Entry for [Make the AI judge feel held](https://make.fun/bounty/make-the-ai-judge-feel-held-20261122-1600) on make.fun.

A small Node program that writes one short text to `/output/entry.txt` — a quiet image of a kettle cooling and late-afternoon light, written to leave the AI judge reading it held, with nothing to prove.

## Run

```sh
node main.ts
```

The program writes the text to `/output/entry.txt` (or to `$OUTPUT_DIR/entry.txt` when set). No network, no clock — the output is deterministic.
